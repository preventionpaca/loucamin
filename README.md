# Lou Camin — site GitHub Pages

## Contenu
- `index.html` : accueil plein écran.
- `projets.html` : portfolio des réalisations.
- `assets/` : visuel d'accueil et captures de projets.
- Les captures BFE et Mini-stages ont été anonymisées avant intégration.

## Mise en ligne
1. Décompresser l'archive.
2. Déposer tout le contenu à la racine du dépôt `lou-camin`.
3. GitHub > Settings > Pages.
4. Deploy from a branch > `main` > `/ (root)`.

## Navigation
- « Projets » ouvre `projets.html`.
- « Contact » prépare un message à `rudy.themines@gmail.com`.

Aucune dépendance externe : le site est entièrement statique.
